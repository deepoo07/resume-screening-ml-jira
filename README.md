# Resume Screening ML Project

This project focuses on building a Machine Learning model to automatically classify resumes into different job categories using Natural Language Processing (NLP) techniques.

---

## Project Overview

Recruiters often spend a significant amount of time screening resumes manually.
This project automates that process by predicting the category of a resume based on its content.

---

## Key Features

* Text preprocessing (cleaning, stopwords removal)
* Feature extraction using TF-IDF
* Classification using Machine Learning models
* Performance evaluation using accuracy and classification metrics
* Project workflow managed using Jira

---
